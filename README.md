# CVD latent space

MEng research project (King's College London). Can the latent space of a medical language model (MedGemma) be organised into distinct regions for four cardiovascular diseases: atrial fibrillation, heart failure, myocardial infarction and stroke?

## Data

MIMIC-IV is credentialed data from PhysioNet. No data, derived text, vectors or model weights are kept in this repository.
